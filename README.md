# homebrew-tap

Homebrew tap for [LocalPilot](https://github.com/arpitbhalla1801/localpilot).

```bash
brew install arpitbhalla1801/tap/localpilot
```

Formulas in this tap are published automatically by [goreleaser](https://goreleaser.com) as part of LocalPilot's release process — do not edit `Formula/*.rb` by hand.
